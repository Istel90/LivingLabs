# GK2A 로컬 다운로드 관제

`대시보드-열기.cmd`를 실행하면 서버를 시작하고 http://127.0.0.1:4187 을 엽니다. 이미 실행 중이면 같은 서버를 사용합니다. 재부팅 후에는 다시 실행해야 합니다. Node.js가 필요합니다.

`D:/90_Data/gk2a-ndvi`의 설정·상태·실행 로그와 Windows의 GK2A 예약 두 개만 읽습니다. API 인증키를 읽거나 다운로드를 실행하지 않습니다. 인터넷에 게시하지 않으며 127.0.0.1에만 바인딩합니다. 상태·로그는 5초, 예약은 30초마다 갱신합니다.

2026-09-29 재확인: 사용자는 2026-08-23부터 2024-08-23까지 모든 계절의 매일 10~15시 KST, VI006/VI008을 과거 방향으로 수집하도록 요청했습니다. 8월 28일 '천리안 위성영상 수집 확인' 대화에서 이전 기간은 4인 배포 패키지로 분담했습니다. 최신 자료를 계속 추가하는 원시자료 작업이 아닙니다.

9월 15일 19:06:56 KST에 2024-08-23 10시 KST까지 도달했습니다. 대상 8,772건 = 다운로드 8,231 + 자료 없음 541 + 미처리 0. 9월 29일 실제 .nc 8,231개와 기록상 파일 크기가 모두 일치합니다(내용·품질 전수 검증은 아님). 더 과거로 가지 않는 이유는 설정된 담당 시작일 도달입니다. 541건은 코드상 HTTP 404 기록으로 자동 재시도하지 않으며 원본의 영구 부재를 뜻하지 않습니다.

별도 NDVI 완성자료 수집기는 2019-07-25부터 8일 간격이며 현재일까지 새 주기를 확인합니다. 원시자료와 목적이 다릅니다.

수집 중 파일 내부 전송률은 수집기가 제공하지 않습니다. 화면은 저장된 파일 완료 기록과 실행 상태를 표시하며 바이트 단위 실시간 전송률을 추정하지 않습니다.
