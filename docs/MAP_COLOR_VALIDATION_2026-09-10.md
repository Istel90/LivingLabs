# 행정구역별 지도 색상 검증

- 분석용 값과 Hotspot 선정 기준은 유지한다. 표시 색상만 조절한다.
- 기본: 선택한 행정구역의 표시 격자 5–95 백분위 사이를 연속 색상으로 표현한다. 범위 밖 값은 끝 색으로 표시하고 범례에 안내한다.
- 지역 전체 범위: 표시 격자 최솟값–최댓값 사용.
- 공통 점수: 0–1 사용. 지역 간 비교 시 선택한다.
- 값이 모두 같으면 단색으로 표시하고 안내한다. 없는 값을 0으로 만들지 않는다.
- WBGT 단독 표시에는 원자료 환산 범위가 있으면 ℃ 범례를 표시한다.
