# 건물·지형의 그림자와 복사환경을 반영한 WBGT — 자료 확보 점검

확인일: 2026-09-07. 이번 작업은 자료 점검과 샘플 확보이며 플랫폼 계산 변경은 하지 않았다.

후속 결정: 사용자는 전국 공개 DEM 약 90m × 90m의 순차 확보를 요청했다. 2026-09-08에 안양 37612와 성동 37705의 원본 ZIP·IMG를 검증했으며 실제 해상도 90m × 90m, EPSG:5179를 확인했다. 저장 위치는 `D:/90_Data/LivingLabs/sources/NGII_DEM90/`이고, 2025년 전국 조회 목록 300개 중 2개 보관 상태다. 10m 자료의 전국 공개 확보 가능성을 확인하면 우선 검토한다. 세부 진행 상황은 [전국 DEM 다운로드 진행 기록](NGII_DEM_DOWNLOAD_STATUS_2026-09-07.md)과 보관 폴더의 `manifest.json`을 따른다.

## 확정 범위

- 건물 외곽선과 유효 높이를 사용하고, 높이 결측은 지상층수 × 3.3m로 추정한다. 높이·층수가 모두 없는 레코드는 0m로 간주하지 않는다.
- 지형은 지면 고도 자료를 사용한다. 수목은 이번 모델에서 제외한다.
- 건물·지형의 시간별 그림자와 복사환경을 계산하여 WBGT를 보완한다. 상세 계산 후 100m 격자로 집계하는 구조를 검토한다.
- 건물 반영만으로 국지 기온·습도·바람까지 검증되는 것은 아니다. 이번 범위는 그림자와 복사환경 보완이다.
- 플랫폼 기준은 `/internal-tools/priority-management-area/flood?regionCode=41110`; WBGT 적용 대상은 같은 플랫폼의 heatwave 경로다.

샘플은 `output/wbgt_data_availability/`에 저장했다. `probe_manifest.json`에는 인증키 없이 요청 인자, 응답 크기, 해시와 앞부분을 기록했다. 샘플 성공은 전체 기준기간 확보 완료를 뜻하지 않는다.

500m 수원 지점(127.0286, 37.2636) 샘플: 기온 33.9°C, 상대습도 52.4%, 풍속 0.7, 현지기압 998.4hPa. API의 `ws_10m` 설명은 **10분 평균풍속**이므로 이름만으로 관측 높이 10m라고 해석하지 않는다. 응답에는 `TM` 요약행도 있어 시각 자료행과 분리해야 한다.

## 건물 높이의 실제 확보율

기존 DB 점검 결과를 바탕으로 양수 높이 또는 결측 높이에 양수 지상층수가 있는 레코드를 합산했다. 고유 건물 중복 제거 전이며 값의 정확성 검증 전이다.

| 지역 | 원본 레코드 | 높이 또는 층수로 보완 가능한 레코드 | 둘 다 없어 추가 처리가 필요한 레코드 |
|---|---:|---:|---:|
| 수원 | 98,753 | 57,078 (57.8%) | 41,675 |
| 강남 | 28,228 | 22,251 (78.8%) | 5,977 |

원본 위치와 속성 정의는 `WBGT_EXISTING_BUILDING_DATA_2026-09-07.md` 참고. 2026년 보관 건물과 2021–2025년 기상을 결합하면 ‘현재 건물 환경에 과거 기상을 적용한 추정’이라는 시점 가정이 필요하다.

## 지형 자료에서 발견한 문제와 확보 후보

기존 원본 경로:
`D:/90_Data/LivingLabs/PORTABLE_2026-08-28/02_processed_outputs/project_generated_data/LivingLabs_flood_national/07_terrain/copernicus_glo30/`

직접 읽은 N37 E127 원본은 EPSG:4326, 1 arc-second 간격이다. `processed/terrain_elevation_100m_epsg5179.tif`는 EPSG:5179, 100m다. Copernicus 공식 설명상 원본은 건물·기반시설·수목이 포함된 DSM이다. 이에 건물 높이를 다시 더하면 중복 반영 가능성이 있고 수목 제외 조건도 지키기 어렵다. 100m 재표본화는 이 문제를 해결하지 않는다.

1. **우선 확인 대상: 국토지리정보원 지면 DEM/DTM.** 공식 자료에서 1m·5m·10m 수치표고모형 구축은 확인된다. 국토정보플랫폼에서 수원·강남 도엽의 실제 제공 해상도, 지면 분류, 취득연도, 다운로드 조건을 확인해야 한다. 이번 점검에서 해당 도엽 다운로드나 공개 API 사용 가능성까지 확인한 것은 아니다.
2. **대안 후보: FABDEM.** Copernicus의 건물·수목 영향을 모델로 제거한 약 30m 자료. Bristol V1-2 배포 목록과 CC BY-NC-SA 4.0 라이선스를 확인했다. 플랫폼 이용 형태에 맞는 조건 검토가 필요하며 아직 지역 파일은 확보하지 않았다. 상세 지면 실측 자료와 같은 정확도를 가정하지 않는다.

## 추가로 필요한 입력과 계산에서 만들 항목

- 태양 위치: 좌표·날짜·시각으로 계산 가능. 별도 관측 데이터 구매 불필요.
- 직접/산란 일사: 확보 전천일사에서 분리 추정 가능. 위성 일사도 전천일사이므로 건물 그늘이 이미 반영된 자료가 아니다.
- 그림자·하늘이 보이는 비율: 지면 고도와 건물 도형·높이로 계산할 항목.
- 반사·장파복사: 지면·벽의 반사율, 방사율, 표면온도 또는 표면온도 추정식이 필요하다. 현재 건물 원본만으로 재료별 값을 확보했다고 볼 수 없다. 초기 모델에서는 명시적 가정과 민감도 확인이 필요하다.
- 그늘에서 직접광이 차단되더라도 산란광·반사광·장파복사를 모두 0으로 처리하지 않는다.
- 기상 분석 격자를 100m로 재표본화하는 것만으로 100m 기상 정확성이 생기지 않는다.
