# 저장 대안 겹침 비교 · 작업 기록 및 복구

## 겹침 결과를 대안 옆 탭으로 열기 (2026-09-10)
- 비교 실행 후 `결과 탭으로 열기` 버튼을 누르면 모달을 닫고 기존 대안 옆에 `겹침 결과 N` 탭을 추가한다.
- 결과 탭은 계산 완료 시점의 스냅샷이다. 원본 대안을 바꿔도 자동 재계산하지 않는다. 지표 수정은 원래 대안 탭에서 한다.
- 겹침 지도, 최소 횟수, 후보 필지, 출처 대안·임계값·가중치, JSON 다운로드를 유지한다.
- 결과 탭은 기존 IndexedDB 저장소의 `priority-overlap-tabs/v1:<hazard>:<regionCode>` 별도 레코드에 저장한다. 새로고침 후 탭 목록을 복원하며, 다른 지역·재해 탭은 표시하지 않는다. 브라우저 데이터 삭제 또는 다른 브라우저/컴퓨터에서는 유지되지 않는다.
- Supabase 저장/검토요청에 겹침 결과를 일반 대안으로 혼합하지 않는다. 결과 탭에서는 해당 버튼을 비활성화하고 로컬 보관 범위를 표시한다.
- 탭 닫기는 해당 로컬 결과 탭만 제거한다. 원본 Supabase 저장본은 유지한다.
- 직전 코드/실행 파일 백업: `output/overlap-tabs-backup-20260910/`. 기존 복구 절차와 동일하게 원래 소스 및 `pages-dist/internal-tools/`로 복사한다.

## 최신 결정: 현재 작업 지역 자동 적용 (2026-09-10 UI 수정)
사용자 요청에 따라 모달의 행정구역 선택을 제거했다. 이전 화면에서 선택한 현재 `regionCode`와 재해로 저장본을 조회하고, 불러오기·겹침 비교 모두 해당 지역에 자동 고정한다. 아래의 전 지역 조회/지역 선택 설명은 이전 구현 기록이며 최신 동작이 아니다.

비교 지도도 초기부터 해당 지역 범위로 맞춘다. 불러오기/비교 탭은 선택 상태가 구분되는 버튼으로 정리하고, 모달 제목·닫기·하단 새로고침은 고정하며 내부 내용만 스크롤한다. 선택 필드와 버튼의 간격·크기·포커스 스타일을 조정했다.

수정 직전 소스 및 실제 서비스 파일 백업: `output/current-region-ui-backup-20260910/`. 해당 폴더의 소스 경로와 `served-internal-tools/`를 각각 원래 소스 및 `pages-dist/internal-tools/`로 복사하면 직전 UI로 복구할 수 있다. Supabase 데이터 변경은 없다.

- Supabase 저장 대안을 여러 개 골라 반복 선정된 격자와 후보 필지를 검토한다.

## 계산 정의
- 기본 목록은 작업자+프로젝트 이름별 최근 저장본이다. 독립 분석 세트 ID가 없으므로 임의로 독립 의견으로 간주하지 않는다. 선택은 수동이며 이전 수정본도 사용자가 표시할 수 있다.
- 행정구역별 목록 추가 이후에는 현재 재해의 접근 가능한 저장본을 100건씩 페이지 조회하여 모두 표시한다. 행정구역을 선택해 해당 지역 안에서 비교한다.
- 같은 지역·재해·EPSG:5179·100m 크기·행열·원점의 격자만 허용한다. 다른 정렬을 자동 합산하지 않는다.
- 저장된 Hotspot 임계값 또는 각 대안의 상위 5/10/20/30% 임계값을 사용한다. 동점은 모두 포함하므로 실제 선정 비율이 커질 수 있다.
- 각 격자는 대안당 최대 한 표. 결측은 0으로 바꾸지 않고 유효자료 수를 별도 보고한다.
- 후보 필지 전체의 PNU를 대안 내 중복 제거 후 합산한다. 사용자가 최종 확정한 필지만의 집계나 경계 중첩 면적 계산은 아니다.
- 지도는 격자 중첩을 표시한다. 후보 필지는 목록에서 출처를 확인하며 이 버전에서 필지 경계 지도는 제공하지 않는다.
- JSON에는 격자 위치, 선택된 대안 출처·가중치·지표, 임계값, 중첩 결과를 포함한다.

## 행정구역별 저장 이력 추가 (2026-09-10 후속)

- 직전 버전 백업: `output/administrative-draft-backup-20260910/` (수정 대상 소스 4개와 서비스 파일 전체).
- 불러오기 창에서 시도 → 시군구 → 저장본 순으로 표시하며 저장본 수와 분석 결과가 있는 대안 수를 구분한다.
- 여러 지역이 있으면 그룹을 접어 보여 전체 지역을 먼저 파악할 수 있다. 한 지역뿐이면 펼쳐 보인다.
