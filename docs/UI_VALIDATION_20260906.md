- 기능 기준: master, 7f7721eea351790c1e09e4b63cbc4be463289018
- 검증 브랜치: codex/ui-master-validation
- 검증 주소: http://127.0.0.1:4273/internal-tools/priority-management-area/heatwave?regionCode=41110

## 통합과 수정

UI 브랜치는 master보다 오래된 기능 기반에서 갈라졌다. master를 별도 검증 브랜치에 병합하고 충돌한 세 화면 파일은 최신 UI의 구성과 스타일을 우선했다. 전역 app.css는 UI 커밋과 동일하게 유지했다. master의 기후위험 실험실, 분석 서비스, 데이터 파일과 지도 후보 선택 기능을 복원했다.

추가로 발견해 수정한 기능 오류:

1. 인구 격자 요청이 /internal-tools/population/grid로 향해 404가 발생했다. /population/grid로 수정해 실제 고령·유아 인구를 사용한다. master에서도 동일한 404를 확인했다.
2. 후보 선택 시 인자 없는 Leaflet map.closeTooltip 호출이 예외를 발생시켰다. 후보 레이어별 closeTooltip 호출로 수정했다.
3. 지역 이동 effect가 분석 레이어 상태까지 추적하고 후보 확대 애니메이션이 반복되어 전체 지역 보기로 되돌아갔다. 지역 이동 처리의 내부 의존성 추적을 분리하고 후보 이동은 즉시 적용하도록 수정했다. 최종 브라우저 검사에서 3km 축척→50m 확대 유지 및 수원시 복귀를 확인했다.

## 남은 제한 및 미검증

- 미래 SSP245/2050/H04: master와 검증 서버 모두 HTTP 400, future hazard grid is not loaded. 화면은 대체 패턴으로 계산하므로 실제 미래 분석 정상으로 판정할 수 없다.
- 생태계: 원자료 연결 대기. 기본 분석은 사용 가능 지표 없음 안내로 차단됨.
- 그늘, 어린이집 좌표, 빗물받이, 배수펌프장 등 연결 대기 지표는 미구현 데이터 상태 그대로 유지.
- PNG 내보내기: 내장 브라우저에서 고해상도 PNG 생성 중 상태가 장시간 지속. 완료 미확인.
- 설정 JSON 내보내기: 버튼 동작 후 브라우저 다운로드 이벤트 미확인. 파일 생성 성공으로 판정하지 않음.
- 원격 저장·불러오기, 실제 부서 전달·취소는 외부 기록에 영향을 줄 수 있어 이번 분석 검증에서 수행하지 않음.
- 실제 GeoTIFF/격자 JSON 업로드, 모든 지역·격자 크기·가중치 조합은 미검증.

현재 결과는 핵심 분석 통합 검증본이며 최종 master 반영 준비 완료 판정이 아니다.

## 실행 환경

세 앱 node_modules는 기존 master 폴더의 설치본을 연결해 사용한다. .env.local은 기존 키를 유지하고 로컬 주소를 4273으로 변경했다. DB는 읽기용 분석으로 공유하고 UI 테스트는 별도 포트의 브라우저 저장 공간을 사용했다. API 결과는 .runtime-logs/analysis-api-results.json, 빌드 기록은 .runtime-logs/ui-validation-build.log에 있다.
