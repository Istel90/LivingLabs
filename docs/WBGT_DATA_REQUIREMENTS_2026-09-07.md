# WBGT 사전계산 및 H 지표 추가 — 자료 확보 체크리스트

> 후속 진행: ASOS 전국 2021–2025년 WBGT 사전계산 및 시험용 H11 연결을 완료했다. 최신 상태는 [구현 결과](WBGT_ASOS_IMPLEMENTATION_2026-09-07.md)를 따른다. 아래의 미구현·자료 미확보 설명은 당시 검토 시점의 기록이다.

작성일: 2026-09-07

## 이번에 정리한 방향

WBGT를 사전계산하여 저장하고 플랫폼에서 사용자가 선택할 수 있는 H 지표로 제공한다. 지표 선택·조합 규칙은 사용자가 필요에 따라 별도로 정한다. 이번 작업의 범위는 계산에 필요한 자료와 추가 확보 항목을 정리하는 것이다. 실제 자료 수집·WBGT 계산·H 등록은 아직 수행하지 않았다.

현재 관측자료 기반 추정부터 시작하고 미래 SSP 자료로 확장한다. 여기서 현재는 실시간 날씨가 아니라 기존 H와 비교할 수 있는 최근 기준기간의 평가를 우선 뜻한다. 기준기간 2021–2025년, 6–9월은 기존 검토와 연결한 제안이며 확정값은 아니다.

## 1. 계산에 필요한 정보

야외 일사 노출 WBGT를 기준으로 한다. 기상자료에서 자연습구온도와 흑구온도를 추정하는 Liljegren 계열 물리 계산이 우선 후보다. 아래 값은 같은 위치·같은 시각 또는 명시적으로 일치시킨 시간 구간에 대응해야 한다.

| 항목 | 확보할 값·단위 | 확인할 설명 |
|---|---|---|
| 기온 | 지상 기온, °C | 관측 높이. 지표면온도 LST와 구별 |
| 습도 | 상대습도, % | 이슬점으로도 환산 가능. 비습은 기압 등 환산 조건 필요 |
| 풍속 | m/s | 관측 높이 필수. 계산 높이에 맞춘 변환 방법 기록 |
| 일사 | 지표면 하향 단파복사/수평면 전일사, W/m² | 시간 누적 MJ/m² 자료도 가능하나 누적 구간·초기화 규칙 확인 |
| 기압 | 현지기압/지표기압, hPa 또는 Pa | 해면기압과 구별. 미제공 시 고도 기반 추정 여부와 가정 기록 |
| 위치·시간 | 지점/격자 ID, 위경도, 날짜·시각, 시간대 | UTC/KST, 순간값/평균값/누적값, 구간 시작·끝 구별 |
| 부가정보 | 고도, 관측 높이, 결측 코드, 품질표지 | 지점 이동, 자료 출처·버전, 공간해상도 포함 |

선택한 계산 구현에 필요한 일사 직달·산란 분해, 지면 반사율, 센서 특성 등은 실제 추가 입력과 모델 가정으로 구분해 남긴다. 흑구·자연습구 실측값은 기상자료 기반 추정의 필수 수집 항목은 아니며, 있으면 검증에 유용하다. 강수량·인구·취약계층은 WBGT 자체 계산 입력이 아니다.

근거: [시간별 기상자료를 이용한 WBGT 계산 연구](https://www.nature.com/articles/s41597-022-01405-3), [NWS WBGT 설명](https://www.weather.gov/ict/wbgt).

| 날짜·시각·관측소 | 수집 코드에 있음 | 지점 메타데이터와 관측 높이 연결 |

## 3. 사용자가 추가로 찾아볼 자료

### A. 현재 평가용: 가장 먼저 찾아볼 것

- [ ] 대상 지역의 **날짜별 시간별 일사량**. 우선 2021–2025년 6–9월의 제공 여부 확인.
- [ ] 일사를 제공하는 지점에서 **같은 시각의 기온·습도·풍속·현지기압**도 함께 확보 가능한지 확인.
- [ ] **하루 전체 시간** 자료인지 확인. 13–15시만 확보하면 그 시간대 최대값으로 이름 붙여야 하며 일최대라고 표시하지 않음.
- [ ] 관측소 ID·위경도·고도·풍속계 높이·결측 및 품질표지 설명 확보.
- [ ] 전국 적용을 위해 일사 관측소의 공간 분포와 미관측 지역을 확인.

첫 자료원은 [기상청 ASOS 시간자료](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=4)다. 일사와 기온·습도·바람·기압을 제공하지만 지점·기간별 실제 제공 여부는 따로 확인한다. 검색어 예: “기상청 ASOS 시간자료 일사 현지기압 상대습도 풍속”, “ASOS 지점정보 풍속계 높이”.

처음에는 일사가 있는 동일 관측소의 기상변수 묶음으로 계산을 확인하는 것이 수월하다. 이후 AWS와 결합하려면 일사 지점 차이의 보간 방법을 정한다. 관측소 사이 공간화를 통해 만든 격자는 해당 보간 방법과 원자료 해상도를 함께 표시한다.

전국의 연속된 시간별 격자가 필요하면 [ERA5-Land](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land?tab=overview)도 후보로 검토한다. 기온·이슬점·풍속 성분·기압·일사 자료의 변수 정의와 누적 처리부터 확인하고 관측자료와 비교한다. 이는 관측소 실측값과 구분하여 재분석 기반 추정으로 표시한다.

### B. 미래 평가용: 찾을 때 함께 확인할 것

| 확인 항목 | 필요한 조건 |
|---|---|
| 기온 | 시간별/시간대별 기온 우선. 일자료는 최고·최저·평균 중 제공 항목 확인 |
| 습도 | 상대습도 또는 환산 가능한 습도 변수 |
| 바람 | 지상 풍속 또는 풍속 성분과 높이 |
| 복사 | 지표면 하향 단파복사 rsds, 단위·시간 적산 여부 |
| 기압 | 지표기압 ps, 없으면 고도 및 기압 추정 가정 검토 |
| 시나리오 묶음 | 같은 기후모델·SSP·날짜·격자의 변수 세트 |
| 과거 자료 | 미래와 연결되는 동일 모델의 과거 기준기간 및 보정 방법 |
| 시간·공간 | 시간별/3시간별/일별 등 간격, 달력, 시간대, 격자 좌표·크기 |

첫 후보는 [농촌진흥청 SSP 다운로드](https://weather.rda.go.kr/appMap/climateDown.do)다. 일 최고·최저기온, 일평균 상대습도·풍속, 일적산 일사량을 안내한다. 해당 페이지 다운로드는 167개 시군 집계자료이므로 격자 원자료가 필요한 경우 별도로 확인한다. 상대습도는 0–1, 일사는 MJ/m²로 안내되어 단위 변환이 필요하다.

[기상청 기후 시나리오 자료 안내](https://www.climate.go.kr/home/CCS/_image/web_manual/data_information.pdf)에서도 고해상도 격자 및 변수별 기간을 확인한다. 안내에 변수가 있다는 사실과 원하는 기간의 원자료를 실제 확보했다는 사실은 구분한다.

일자료만 있어도 후속 검토는 가능하다. 다만 시간대별 변동을 복원하거나 관측 시간자료에 시나리오 변화를 반영하는 방법을 현재 자료로 검증해야 한다. 일최고기온에 일평균 습도·풍속·일사를 단순 결합한 값을 실제 일최대 WBGT라고 취급하지 않는다. 모델별 WBGT를 계산한 뒤 모형 간 분포를 요약한다.

### C. 이미 계산된 WBGT 자료를 찾는 경우

완성된 WBGT 격자/시간자료도 후보로 받을 수 있다. 아래 설명이 함께 있어야 한다.

- [ ] 야외 일사 노출인지 실내/그늘 조건인지
- [ ] 실측인지 추정인지, 계산 방법과 버전
- [ ] 기간, 시간 간격, 공간해상도, 단위
- [ ] 시간별 원값인지 일최대·기간 평균 등 통계값인지
- [ ] 현재/미래 구분, 미래라면 모델·SSP·과거 기준기간
- [ ] 결측·보정 방법, 이용 및 재배포 조건

## 4. 자료를 찾았을 때 남길 정보

자료명 / 제공기관 / 다운로드 또는 API 링크 / 대상 지역 / 기간 / 변수 목록 / 단위 / 시간 간격 / 격자 크기 또는 관측소 목록 / 결측 코드 / 품질정보 / 미래 모델·SSP / 사용 조건을 남긴다.

전체 자료를 먼저 대량 다운로드할 필요는 없다. 설명서와 하루 또는 한 달 분량의 변수 세트 샘플이면 시간·단위·공간 연결 가능성을 먼저 판단할 수 있다.

## 5. 사전계산 결과를 H 지표로 연결하는 방식

원자료 확보 → 시간·위치·단위 정합 및 품질 확인 → 시간별 추정 WBGT 사전계산 → 일별·기간별 통계 및 공간자료 저장 → H 선택 목록 연결.

- 시간별 WBGT 원값(°C)을 보관해 집계 정의가 바뀌어도 원자료부터 다시 수집하지 않게 한다.
- 일최대, 기간별 평균·백분위값 등을 만들 수 있도록 유효 시간 수와 결측 상태를 함께 저장한다. 일최대 인정에 필요한 자료 충족 기준은 계산 전에 정한다.
- H11은 후보 코드다. 기존 검토의 “고온기 일최대 WBGT의 90백분위값”도 후보로 유지하며 이번에 확정하지 않는다.
- H 평가용 대표 통계·공간 레이어를 미리 저장하고 사용 시 불러온다. H 점수 변환·사용자 가중치 계산은 물리 WBGT 사전계산과 분리한다.
- 현재와 미래를 비교할 때 원값을 보존하고 같은 비교 기준을 적용할 수 있도록 기준기간·변환 정의를 저장한다.
- 모델 버전, 입력 출처, 계산 조건, 풍속 높이 변환, 일사 처리, 공간 보간, 결측 처리, 기준기간을 결과와 함께 보관한다. 나중에 플랫폼의 “사용한 가정” 표시에도 활용한다.

다음 구현의 출발점은 **현재 자료의 일사 포함 샘플과 관측소 메타데이터 확보**다. 이 자료로 WBGT 계산을 검증하고, 필요한 범위의 사전계산을 마친 뒤 선택 가능한 H 지표로 등록한다.
