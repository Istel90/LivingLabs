# 대안 없는 시작 화면

- 홍수·폭염 공유 화면의 새 세션은 기본 대안 1·2·3 없이 시작한다.
- 중앙 화살표 버튼과 “화살표를 눌러 대안 탭을 만들어 주세요.” 안내를 표시한다.
- 중앙 화살표 또는 상단 + 버튼을 누르면 대안 1부터 생성한다.
- 대안이 없을 때 지표 편집·분석·저장을 막고 저장본 불러오기는 허용한다.
- 마지막 대안도 확인 후 삭제할 수 있으며, 자동으로 대안을 다시 만들지 않는다.
- 명시적으로 요청한 저장본 불러오기 및 임시 저장 복원은 유지한다. 저장본 자체는 삭제하지 않는다.
