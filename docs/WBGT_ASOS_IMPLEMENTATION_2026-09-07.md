# ASOS WBGT 계산 및 H11 시험 적용 결과

작성일: 2026-09-07

## 완료한 내용

ASOS 시간별 일사량을 이용한 WBGT 사전계산을 수행하고 **H11 · 추정 WBGT P90 (시험)**을 기후위험 실험실과 우선관리지역의 현재 자료 선택 목록에 연결했다. 선택 시 저장된 결과를 읽으며 WBGT 물리 계산을 다시 실행하지 않는다. 미래 SSP는 아직 미제공이다.

| 항목 | 결과 |
|---|---|
| 기간 | 2021–2025년, 매년 6–9월, 하루 전체 시간 |
| 확인한 전국 관측소 | 97개 |
| 시간격자 레코드 | 1,411,296개(지점별 존재 연도·월 기준) |
| WBGT 산출 가능 시간 | 801,328개 |
| 24시간 산출 가능한 관측소·일 | 33,003개 |
| 5개년 자료 충족 기준 통과 지점 | 44개 |
| 전국 100m 분석격자 유효 셀 | 19,311,100개 |
| 공간 보간 교차검증 MAE / RMSE | 0.826℃ / 1.156℃ |

자료 충족 기준은 하루 24개 시간 추정값, 매년 6–9월 유효일 90% 이상, 5개 연도 모두 충족이다. 미충족 지점의 시간별 계산 가능 값도 원자료와 함께 보관했다. 44개 지점은 이번 기준을 통과한 지점 수이며 전국의 일사 관측소 총수와 같지 않다.

## 이번 시험용 H11의 정의

연도별 6–9월 일최대 추정 WBGT의 90백분위값을 구한 뒤, 2021–2025년을 평균한다. 사용자가 선택하는 시험 지표다. 기간 통계 정의를 바꾸더라도 시간별 WBGT를 재집계할 수 있다.

수원(119)은 총 610일 중 604일에서 24시간 값이 확보됐다. 연도별 P90은 2021년 32.960℃, 2022년 32.189℃, 2023년 32.707℃, 2024년 33.122℃, 2025년 32.437℃로, 5개년 평균은 32.683℃다. 이는 선택한 추정 모형과 집계 정의의 결과이며 일반 기온이나 안전 임계값을 뜻하지 않는다.

## 중요한 계산 조건

야외 일사 노출 조건의 Liljegren 계열 모형을 사용한다. 시간적산 일사를 시간평균 복사로 변환하고 중앙 시각 태양각과 짝지었다. 풍속계 관측 높이를 반영했고 직달·산란 비율은 추정했다. 낮의 결측은 계산하지 않으며 일부 야간의 일사 결측은 태양위치를 확인한 후 0 가정과 별도 표지로 처리했다. 관측 QC는 미제공 상태로 남겼다.

지도는 44개 관측소의 추정값을 기존 H 지표와 동일한 계열의 IDW 방법으로 보간한 것이다. **100m 필지별 미기후를 새로 계산한 결과는 아니다.** 공간 교차검증 수치는 보간 오차를 평가한 값이고 직접 WBGT 센서와의 검증 오차가 아니다.

## 검증과 적용 범위

- 12개 계산·자료처리·보간 테스트 통과. 공개 thermofeel Liljegren 기준 결과 포함.
- 수원 표본일 시간별 일사 합계와 기상청 공식 일합계 일치.
- 수원·서울 종로·제주 H11 격자 조회, 기존 H02 격자 정렬, 값 범위 및 미래 요청 차단 확인.
- 변경된 Svelte 앱 빌드 성공. 기존 CSS·접근성 경고는 남아 있다.
- 후속 플랫폼 확인: 내부 도구를 /internal-tools 경로로 재빌드하여 pages-dist에 반영하고 로컬 4173 서버를 재시작했다. 실제 Chrome에서 H11 체크 및 분석 버튼 클릭 후 HTTP 200, 수원 100m 유효 12,100셀 수신을 확인했다. 페이지 오류는 없었으며 미래 모드에서 H11 비활성도 확인했다. 외부 공개 사이트는 별도 검증하지 않았다.

## 후속 작업

국내 WBGT 실측 비교, 직달·산란 및 풍속 변환 가정의 민감도, 희소 관측지역 보간 불확실성을 확인하며 시험 지표를 보완한다. 미래 시점은 SSP 입력자료의 시간 단위와 보정 방법을 확인한 뒤 별도로 계산한다.


## 실제 플랫폼 경로 정정 및 재검증

앞선 확인은 별도 `climate-hazard-demo` 화면을 사용했으므로 실제 우선관리지역 플랫폼의 화면 검증으로 간주하면 안 된다. 사용자 지정 기준은 `/internal-tools/priority-management-area/flood?regionCode=41110`이며 같은 플랫폼의 폭염 화면은 `/internal-tools/priority-management-area/heatwave?regionCode=41110`이다. 두 재해 화면은 `PriorityManagementArea.svelte`를 공유하고 데모는 별도 `ClimateHazardLab.svelte`를 사용한다.

후속으로 **실제 폭염 경로**에서 H11 체크와 분석 버튼 클릭을 다시 수행했다. H11 응답 HTTP 200, EPSG:5179 100m 수원 유효 12,100셀, 관측소 44개, 페이지 오류 없음, 미래 모드 H11 비활성을 확인했다. 사용자가 지정한 실제 침수 경로도 열어 홍수 화면과 지표 구성을 확인했다. WBGT는 같은 플랫폼의 폭염 지표에 있으며 침수 지표에 혼합하지 않았다.

재현 검사: `scripts/wbgt/verify-platform-browser.py`. 검사에 실제 경로와 화면 제목 확인을 포함했다. 향후 작업의 기준 경로와 검증 원칙을 루트 `AGENTS.md`에 기록했다. 화면 구현 중복 자체를 통합한 것은 아니며 전체 구조 개편은 별도 후속 과제다.
