# NGII 전국 공개 DEM 확보 진행 상태

최신 상태(2026-09-08): **샘플 다운로드 재현에 성공했고 검증·보관 2개, 전국 2025년 조회 목록은 300개다. 전국 확보 완료 상태는 아니다.** 아래 2026-09-07의 차단 기록은 과거 시도 이력이다.

보관 위치: `D:/90_Data/LivingLabs/sources/NGII_DEM90/`. 최신 파일 상태는 해당 폴더의 `manifest.json`과 `README.md`를 따른다. 성동 37705는 에이전트가 직접 전송했으며, 사용자 다운로드 안양 37612와 함께 ZIP 검사·실제 래스터 읽기에 성공했다. 두 파일의 실제 해상도는 90m × 90m, 좌표계는 EPSG:5179다. 별도 INNORIX 창의 `전체 다운로드` → `전송시작` 단계가 필요하다. 최대 17개씩 신청할 수 있다.

## 사용자 결정과 권한

- 국토지리정보원의 전국 공개 DEM 약 90m × 90m를 순차적으로 확보한다. 공개적으로 확보할 수 있는 전국 10m 자료가 확인되면 우선 검토하되, 현재 확보 대상은 공개 DEM이다.
- 사용자는 전국 자료 다운로드, 신청서 생년월일 입력, 사용자 준수사항 동의, 교육·학습 용도 선택을 명시적으로 요청했다. 같은 내용의 동의를 다시 요청할 필요는 없다.
- 개인정보인 생년월일은 이 파일과 수집 목록에 저장하지 않는다.
- 건물 높이는 유효 높이를 우선 사용하고 결측 시 지상층수 × 3.3m로 보완한다. 지형을 반영하며 수목은 제외한다.
- 플랫폼 계산이나 화면은 이번 다운로드 시도에서 수정하지 않았다. 기준 화면은 `http://127.0.0.1:4173/internal-tools/priority-management-area/flood?regionCode=41110`이다.

## 직접 확인한 신청 경로

1. 로그인한 Chrome에서 [국토정보맵](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total#none)을 열었다.
2. 간편선택 → DEM → 제작년도 2025년 → 다음 → 행정구역으로 선택 → 서울특별시 / 강남구 → 다음.
3. 결과는 `2025 서울특별시`, `2025 성동`, `2025 수원` 3개다. 이는 강남구 검색 결과이며 전국 자료 목록이 아니다.
4. 전체 다운로드와 서울특별시 1개 선택 다운로드를 각각 시도했다.
5. 생년월일은 달력의 년도와 일자를 선택한 후 입력란의 실제 표시값을 확인했다. 단순한 8자리 텍스트 입력은 신뢰하지 않는다.
6. 사용목적은 `제작 및 활용` → `교육, 학술, 연구`, 상세용도는 `교육 및 학습을 위한 전국 지형 분석과 폭염 WBGT 산정 연구`로 입력하고 `동의합니다.`를 선택했다.
7. 신청서의 다운로드 버튼을 눌렀으나, 전송 완료 표시나 저장 파일은 확인되지 않았다. 별도의 후속 설문 화면도 확인되지 않았다.

사이트는 항공사진 외 다운로드를 1회 1GB로 제한한다고 안내한다. 안내의 DEM 평균 75MB는 개별 파일 크기의 실측치가 아니다. 제공 제작년도 선택지는 2025, 2024, 2023, 2022, 2021, 2014였다.

## 확인된 문제와 불확실성

- 시도만 선택하면 시도/시군구를 선택하라는 안내가 나왔다. 해당 경고창에서 Chrome 제어가 멈춰 새 탭에서 정상 신청 경로를 다시 진행했다.
- Chrome 신청서 제출 후 [다운로드신청내역](https://map.ngii.go.kr/pd/purchs/downPurchsDtlsList.do)을 확인했으나 오늘 DEM 내역은 확인되지 않았다. 표시된 최신 내역은 기존 국토통계 자료였다.
- `C:/Users/User/Downloads`에서 이번 시도 시각에 새로 저장된 파일을 확인하지 못했다. 다른 저장 위치로의 전송 성공을 확인한 것은 아니다.
- 공식 [국토정보맵 소개](https://map.ngii.go.kr/mi/oprGuide/portalMapGuide.do)의 이용가이드 다운로드 버튼을 누르면 Chrome에 `ERR_BLOCKED_BY_CLIENT`와 ‘Chrome에서 차단한 페이지입니다’가 표시됐다.
- 이 차단이 DEM 전송 문제와 같은 원인인지는 확정하지 않았다. 팝업 차단, 확장 프로그램, 별도 전송 프로그램 중 무엇이 원인인지 아직 미확인이다.
- Edge는 지도에 로그아웃 링크가 있어도 실제 다운로드 버튼을 누르면 로그인 팝업이 열렸다. 재로그인이 필요할 수 있다.
- 현재 제어 도구는 브라우저 웹페이지를 조작할 수 있으나 브라우저 바깥의 설정창이나 Windows 전송 프로그램 창은 조작할 수 없다.

## 재개 시 순서

1. Chrome의 해당 사이트 팝업·다운로드 차단 상태를 사용자 화면에서 확인한다. 차단 원인이 확인되면 필요한 항목만 처리한다. 전체 보안 설정을 일괄 해제하지 않는다.
2. 먼저 서울 DEM 1개가 실제 파일로 저장되는지 확인한다. 같은 신청 정보와 교육·학습 용도, 이미 허용된 준수사항 동의를 사용한다.
3. 파일명·용량·해시·좌표계·격자 간격·경계·NoData를 확인한다. 약 90m라는 목표 사양을 실제 파일 확인 없이 확정하지 않는다.
4. 전국 시군구 또는 지도 영역 검색으로 제공 자료 목록을 확보한다. 지역 검색에 같은 도엽이 반복될 수 있으므로 파일 단위로 중복을 제거한다.
5. 1GB 제한 안에서 순차 다운로드하고 성공·실패·재시도 상태를 기록한다. 최신 제작년도만으로 전국이 모두 덮이는지는 실제 도엽 경계로 확인한다.
6. 제주·도서 지역 및 지역 간 경계의 누락 여부까지 검증한 뒤에만 전국 확보 완료로 표시한다.
