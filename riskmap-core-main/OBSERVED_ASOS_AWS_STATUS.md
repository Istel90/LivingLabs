## 해석 시 주의

- H02·H03·H04·H05·H07은 5개 연도가 모두 있는 ASOS 95개소를 IDW로 공간화한 전국 100m 분석격자다.
- 원자료는 Point 관측이며, 100m는 분석격자 해상도다. 100m 원자료 수준의 공간상세도를 의미하지 않는다.
- AWS 자료는 향후 공간모형 보강·교차검증에 사용할 수 있으며 현재 ASOS IDW V1의 필수 입력은 아니다.
- H06·H08·H09는 최근 5년만으로 계산하면 안 되며, 먼저 1991~2020 기준기간의 일별 최고기온 백분위 기준을 구축해야 한다.
- H06·H08·H09는 기준기간 수집 완료 후 동일한 100m 공간모형 단계로 진행한다.
